```markdown
# PITR Restore Drill

**Frequency:** Quarterly (Mar, Jun, Sep, Dec)
**Owner:** On-call engineer
**Duration:** ~30 minutes

## Pre-drill Checklist
- [ ] Supabase Dashboard accessible with admin credentials
- [ ] PITR enabled (Settings → Database → Point in Time Recovery)
- [ ] Latest successful backup verified (within 24h)
- [ ] Slack/email notification sent: "PITR drill starting on rejira-staging"

## Drill Procedure

### Step 1: Create staging branch from PITR backup
1. Go to Supabase Dashboard → rejira-prod → Database → Backups
2. Click "Restore" on the latest backup
3. Select "Create a new project" (not overwrite production)
4. Name: `rejira-drill-YYYY-MM-DD`
5. Confirm restore — this creates a new Supabase project from the backup

### Step 2: Verify restored database
```bash
# Clone the drill project
supabase link --project-ref <drill-ref>

# Verify schema
supabase db diff --linked

# Verify row counts match production
psql "$DRILL_DB_URL" -c "
  SELECT 'workspaces', count(*) FROM workspaces
  UNION ALL SELECT 'projects', count(*) FROM projects
  UNION ALL SELECT 'issues', count(*) FROM issues
  UNION ALL SELECT 'users', count(*) FROM users;
"
```

### Step 3: Verify application with restored database
1. Create Vercel preview deployment pointing to drill database
2. Set `DATABASE_URL` env var to drill DB connection string
3. Run smoke tests:
   ```bash
   npx playwright test --grep "Critical E2E" --project=chromium
   ```
4. Verify: sign-in, issue list, issue creation, drawer, settings

### Step 4: Clean up
- [ ] Delete drill Supabase project (billing stops immediately)
- [ ] Delete Vercel preview deployment
- [ ] Notify team: "PITR drill complete — restore time: X minutes, all tests passed"

## Success Criteria
- [ ] Restore completed in < 15 minutes
- [ ] All row counts match production
- [ ] All critical E2E tests pass against restored DB
- [ ] Rollback procedure tested (delete drill projects)

## Failure Response
If restore fails or data is inconsistent:
1. Escalate to Supabase support (enterprise plan)
2. Document failure in post-mortem
3. Schedule re-drill within 1 week
```

import { test, expect } from '@playwright/test';

test.describe('Browser Matrix — Core Screens', () => {
  test('Inbox loads and renders issue rows', async ({ page }) => {
    await page.goto('/inbox');
    await expect(page.locator('[data-testid="inbox-page"]')).toBeVisible();
    await expect(page.locator('[data-testid="issue-row"]').first()).toBeVisible();
  });

  test('My Issues loads with filter chips', async ({ page }) => {
    await page.goto('/my-issues');
    await expect(page.locator('[data-testid="my-issues-page"]')).toBeVisible();
    await expect(page.locator('[data-testid="filter-chips"]')).toBeVisible();
  });

  test('Issue drawer opens and closes', async ({ page }) => {
    await page.goto('/my-issues');
    await page.click('[data-testid="issue-row"]:first-child');
    await expect(page.locator('[data-testid="issue-drawer"]')).toBeVisible();
    await page.keyboard.press('Escape');
    await expect(page.locator('[data-testid="issue-drawer"]')).not.toBeVisible();
  });

  test('Command palette opens with Meta+K', async ({ page }) => {
    await page.goto('/inbox');
    await page.keyboard.press('Meta+k');
    await expect(page.locator('[data-testid="command-palette"]')).toBeVisible();
    await page.keyboard.press('Escape');
  });

  test('Settings page loads', async ({ page }) => {
    await page.goto('/settings');
    await expect(page.locator('[data-testid="settings-page"]')).toBeVisible();
  });

  test('Sign-in page is accessible', async ({ page }) => {
    await page.goto('/sign-in');
    await expect(page.locator('form')).toBeVisible();
    await expect(page.locator('input[name="email"]')).toBeVisible();
    await expect(page.locator('input[name="password"]')).toBeVisible();
  });

  // CSS feature detection — verify modern CSS properties work
  test('CSS custom properties (OKLCH) are supported', async ({ page }) => {
    await page.goto('/sign-in');
    const supportsOKLCH = await page.evaluate(() => CSS.supports('color', 'oklch(0.5 0.1 240)'));
    // OKLCH works in Chrome 111+, Edge 111+, Safari 15.4+, Firefox 113+
    // All our target browsers (latest 2) support it
    if (!supportsOKLCH) {
      console.warn('OKLCH not supported in this browser — graceful degradation needed');
    }
  });

  test('Motion/animations work (reduced-motion respected)', async ({ page }) => {
    await page.goto('/inbox');
    // Verify no animation errors in console
    page.on('console', msg => {
      expect(msg.type()).not.toBe('error');
    });
    await page.waitForTimeout(500); // Let animations settle
  });
});
```
