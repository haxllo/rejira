# Plan 07-06: Public REST API

## Objective

REST API with token-based auth, rate limiting, and OpenAPI docs. 5 mutations: create issue, update status, add comment, list projects, get issue.

## Tasks

### Task 1: Create API tokens schema

Create `apps/web/lib/db/schema/api-tokens.ts`:
```typescript
export const apiTokens = pgTable('api_tokens', {
  id: bigserial('id', { mode: 'bigint' }).primaryKey(),
  workspaceId: text('workspaceId').notNull(),
  name: text('name').notNull(),
  token: text('token').notNull().unique(), // hashed
  lastUsedAt: timestamp('last_used_at'),
  createdAt: timestamp('created_at').defaultNow(),
  expiresAt: timestamp('expires_at'),
});
```

### Task 2: Create API auth middleware

`apps/web/lib/integrations/api-auth.ts`:
- `authenticateApiRequest(request)` — extract Bearer token, lookup hash in `api_tokens`, verify not expired, update `lastUsedAt`
- Return `{ workspaceId, token }` or throw 401

### Task 3: Create API routes

`/api/v1/issues/route.ts`:
- GET `/api/v1/issues` — list issues (paginated, filterable)
- POST `/api/v1/issues` — create issue
- GET `/api/v1/issues/:id` — get issue
- PATCH `/api/v1/issues/:id` — update status
- POST `/api/v1/issues/:id/comments` — add comment

`/api/v1/projects/route.ts`:
- GET `/api/v1/projects` — list projects

### Task 4: Create API settings page

Settings page at `/settings/api`:
- Create new API token (with name + expiry)
- Copy token (shown once)
- Revoke token
- List of active tokens with last used
