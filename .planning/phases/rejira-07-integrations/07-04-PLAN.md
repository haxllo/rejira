# Plan 07-04: File Uploads & Previews

## Objective

File attachments via S3-compatible storage (Cloudflare R2). Drag-and-drop, image previews, file type icons.

## Tasks

### Task 1: Create storage helpers

Create `apps/web/lib/integrations/storage.ts`:
- Use `@aws-sdk/client-s3` with R2 endpoint
- `getPresignedUploadUrl(key, contentType)` — generate presigned PUT URL (10min expiry)
- `getPresignedDownloadUrl(key)` — generate presigned GET URL (1hr expiry)
- `deleteFile(key)` — delete from bucket
- Config from env vars: `R2_ENDPOINT`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET_NAME`

### Task 2: Create upload API

Create `apps/web/app/api/storage/upload/route.ts`:
- POST: accept `{ fileName, contentType, fileSize }`, validate (10MB max, allowed types), return presigned URL
- DELETE: accept `{ key }`, delete from storage

### Task 3: Wire file attachments

Update `apps/web/lib/db/actions/issues.ts`:
- After creating an issue with attachments, record file metadata in `attachments` table
- Create `createAttachment` action

### Task 4: File preview component

Create `apps/web/components/primitives/file-preview.tsx`:
- Image files: thumbnail with lightbox
- PDF: embed viewer
- Other: file type icon with download button

### Task 5: Drag-and-drop in issue drawer/creation

Add drop zone in issue drawer (below comments) and create-issue dialog.
