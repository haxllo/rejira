# Plan 07-05: Data Export

## Objective

CSV and JSON export of issues with async generation, email delivery, and progress UI.

## Tasks

### Task 1: Create exports schema

Create `apps/web/lib/db/schema/exports.ts`:
```typescript
export const exports_ = pgTable('exports', {
  id: bigserial('id', { mode: 'bigint' }).primaryKey(),
  workspaceId: text('workspaceId').notNull(),
  type: text('type').notNull(), // 'csv' | 'json'
  status: text('status').notNull().default('pending'), // pending | processing | completed | failed
  url: text('url'),
  requestedAt: timestamp('requested_at').defaultNow(),
  completedAt: timestamp('completed_at'),
  expiresAt: timestamp('expires_at'),
});
```

### Task 2: Create export route

`apps/web/app/api/export/issues/route.ts`:
- POST: triggers async export
- GET with `?id=xxx`: returns status

### Task 3: Create export workers

`apps/web/lib/integrations/export.ts`:
- `generateCSVExport(workspaceId)` — query issues, generate CSV with columns: ID, Key, Title, Status, Priority, Assignee, Project, Labels, Created, Updated
- `generateJSONExport(workspaceId)` — same but JSON array
- Both paginate in batches of 500 via Drizzle

### Task 4: Export settings page

Create settings page at `/settings/exports`:
- Export type selector (CSV/JSON)
- Trigger button
- Progress bar (polling status every 5s)
- Download link when ready
- History of past exports
