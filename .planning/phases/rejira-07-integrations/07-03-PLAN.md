# Plan 07-03: Outbound Webhooks

## Objective

Per-workspace outbound webhooks that fire on issue events. HMAC-signed delivery with retry.

## Tasks

### Task 1: Create webhook schemas

Create `apps/web/lib/db/schema/outbound-webhooks.ts`:
```typescript
export const outboundWebhooks = pgTable('outbound_webhooks', {
  id: bigserial('id', { mode: 'bigint' }).primaryKey(),
  workspaceId: text('workspaceId').notNull(),
  url: text('url').notNull(),
  signingSecret: text('signing_secret').notNull(),
  events: text('events').array().notNull(),
  retryCount: integer('retry_count').default(3),
  enabled: boolean('enabled').notNull().default(true),
  createdAt: timestamp('created_at').defaultNow(),
});
```

Create `apps/web/lib/db/schema/webhook-logs.ts` for delivery logs.

### Task 2: Create webhook delivery system

Create `apps/web/lib/integrations/webhooks.ts`:
- `deliverWebhook(workspaceId, event, payload)` — find enabled webhooks matching event, POST with HMAC-SHA256 signature header, log delivery
- Retry 3x with exponential backoff (1s, 5s, 30s)

### Task 3: Wire into action handlers

In each action (createIssue, updateIssue, setStatus, addComment, etc.), fire webhook after success.

### Task 4: Webhook settings UI

Create settings page at `/settings/webhooks` with:
- List of configured webhooks with status
- Add webhook form (URL, events checkboxes, signing secret)
- Test button (send test event)
- Delete webhook
