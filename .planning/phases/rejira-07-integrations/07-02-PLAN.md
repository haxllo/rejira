# Plan 07-02: Slack DM on Assignment

## Objective

When a user is assigned to an issue, send them a Slack DM with the issue title and deep link.

## Tasks

### Task 1: Add Slack columns to schema

Add `slack_bot_token`, `slack_signing_secret` columns to `workspaceSecurityPolicy`.

Migration `0033_slack_columns.sql`:
```sql
ALTER TABLE workspace_security_policy
  ADD COLUMN IF NOT EXISTS slack_bot_token text,
  ADD COLUMN IF NOT EXISTS slack_signing_secret text,
  ADD COLUMN IF NOT EXISTS slack_team_id text;
```

### Task 2: Create Slack helpers

Create `apps/web/lib/integrations/slack.ts`:
- `getSlackClient(workspaceId)` — reads token from workspace settings, returns Slack WebClient (`@slack/web-api`)
- `sendDM(userSlackId, message)` — send DM with blocks (header + issue link)
- `resolveUserSlackId(userEmail)` — lookup user by email via `users.lookupByEmail`
- DM format: `🔔 You've been assigned *ENG-123: Fix login bug*` with deep link to issue

### Task 3: Wire into setAssignees action

In `apps/web/lib/db/actions/issues.ts`, after `setAssignees` succeeds, call a fire-and-forget `notifyNewAssignee(workspaceId, issueId, newAssigneeIds)` that sends Slack DMs.

### Task 4: Slack events endpoint

Create `apps/web/app/api/webhooks/slack/route.ts`:
- Handle URL verification challenge
- Handle `member_joined` events for linking Slack user IDs
