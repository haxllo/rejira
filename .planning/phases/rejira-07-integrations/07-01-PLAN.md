# Plan 07-01: GitHub PR ↔ Issue Linking

## Objective

Handle GitHub pull_request webhooks, match PR title/body to issue keys (e.g., `ENG-123`), and link them. Webhook verification via HMAC secret.

## Tasks

### Task 1: Add GitHub webhook secret column to schema

<read_first>
- apps/web/lib/db/schema/workspace-security-policy.ts
</read_first>

<action>
Add `githubWebhookSecret: text('github_webhook_secret')` column to `workspaceSecurityPolicy` table in the Drizzle schema.

Create `supabase/migrations/0032_github_webhook.sql`:
```sql
ALTER TABLE workspace_security_policy ADD COLUMN IF NOT EXISTS github_webhook_secret text;
```
</action>

### Task 2: Create GitHub integration helpers

<read_first>
- apps/web/lib/db/actions/issues.ts (existing action patterns)
</read_first>

<action>
Create `apps/web/lib/integrations/github.ts`:

- `verifyGitHubWebhook(signature: string, body: string, secret: string): boolean` — verify HMAC-SHA256
- `extractIssueKeys(text: string): string[]` — regex `([A-Z]+-\d+)` to find issue keys in PR title/body
- `createPRComment(externalId: string, prUrl: string, prTitle: string): Promise<void>` — add a comment linking the PR
</action>

### Task 3: Create GitHub webhook handler

<read_first>
- apps/web/app/api/ (existing route pattern)
- apps/web/lib/integrations/github.ts
</read_first>

<action>
Create `apps/web/app/api/webhooks/github/route.ts`:

- POST handler
- Read `x-hub-signature-256` header and verify HMAC
- Parse `pull_request` event: extract `action`, `pull_request.html_url`, `pull_request.title`, `pull_request.body`
- Extract issue keys from title/body
- For each matched issue, add a comment: `🔗 Pull request #{pr_number}: {pr_title}` with link
- Return 200 OK (fast — webhook should complete within 5s)
- Handle unknown workspace → 404, bad signature → 401
</action>
