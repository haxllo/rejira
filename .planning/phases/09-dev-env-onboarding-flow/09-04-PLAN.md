**Known critical issue (pre-audit):**
The onboarding page at `/onboarding` is unreachable because:
1. `signUp.email()` uses `callbackURL: '/inbox'` — new users are sent to inbox, not onboarding
2. The middleware has no first-login detection — it just checks for session cookie presence
3. The workspace layout has no onboarding redirection logic

**Better Auth context:**
- `signUp.email()` returns session data on success including whether user is new
- `useSession().data` includes `session.createdAt` which can be compared to detect first login
- Better Auth `organization` plugin has `createOrganization` API
- The `callbackURL` in sign-up controls where user is redirected after sign-in

**Design conventions:**
- Spring physics: `ease-spring` cubic-bezier(0.32, 0.72, 0, 1)
- Durations: 120ms / 220ms / 320ms
- Focus rings: 2px accent color, 2px offset
- Surface levels: bg, surface-1, surface-2, surface-3, overlay
- Button sizes: sm (28px), md (36px), lg (48px)
</interfaces>
