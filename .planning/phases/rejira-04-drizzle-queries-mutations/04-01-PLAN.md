<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → RSC | Untrusted: any URL is untrusted input; the active workspace id from `?w=` is attacker-influenced. The RSC helpers must re-validate the user has membership in that workspace (RLS enforces this) |
| Server action → DB | Untrusted: any call site can pass any payload; the server action must `requireAuth()` and run inside `withTransaction()` so RLS evaluates against the right subject |
| RLS context propagation | The transaction wrapper sets `request.jwt.claims` via `set_config(..., true)`; if the third arg were `false`, the JWT claims would persist across pooled connections — a horizontal escalation vector |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Spoofing | withTransaction | mitigate | requireAuth() inside the transaction reads the verified session; we do NOT trust the caller's user id parameter |
| T-04-02 | Tampering | set_config propagation | mitigate | Pass `true` as the third arg to `set_config` (local to transaction); the test asserts this |
| T-04-03 | Repudiation | mapDrizzleError | mitigate | Original error captured in `DbError.cause`; Sentry captures it; user sees only the safe mapped message |
| T-04-04 | Information Disclosure | mapDrizzleError | mitigate | User-facing messages are hardcoded safe strings; no SQL, no schema names, no row ids leak; `INTERNAL` always returns the generic 'Something went wrong' |
| T-04-05 | Denial of Service | statement_timeout | mitigate | 5s statement_timeout + 5s query_timeout; runaway queries are cancelled; DbError maps 57014 → 408 |
| T-04-06 | Elevation of Privilege | RSC active-workspace | mitigate | `getActiveWorkspaceId()` reads the `?w=` from the session's default workspace or a verified URL param; RLS denies cross-workspace reads regardless |
| T-04-07 | Tampering | drizzleLogger params | mitigate | `redactParams` strips password/token/secret/authorization values before they leave the server |
</threat_model>
