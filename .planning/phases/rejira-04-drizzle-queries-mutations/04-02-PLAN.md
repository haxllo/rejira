<objective>
Build every action module that mutates a business table. Each module is pure: an async function that takes a Drizzle transaction and a typed input, runs the write, and returns the row(s) (or true for a write that has no return). Activity log writes happen via the Phase 2 `tg_emit_activity` trigger — application code does NOT insert into `activities`. PostHog events fire from each module via a small `lib/observability/events.ts` helper.

Purpose: Plan 05 (mutation cutover) imports these functions from server actions. The shape `(tx, input) => Promise<row>` keeps the action testable, composable, and RLS-correct (the transaction wrapper sets `request.jwt.claims` once for the whole batch).
Output: 8 action modules, 1 barrel, 1 events helper, 14 unit tests, all `npm run typecheck && npm run lint && npm run build` clean.

</objective>

    - `const [row] = await tx.insert(s.issues).values({...}).returning();`

    - Update the issue; also fetch the prior status for the PostHog event; call `trackStatusChanged({ from: prior, to: status, workspaceId, issueId })`
  - `setPriority({ workspaceId, issueId, priority }: { workspaceId: string; issueId: string; priority: PriorityKey }): Promise<Issue>`

    - Reorder is a position-based update; the issues table has no `position` column today. We store the ordering inside `saved_views.filter` (a JSON sort spec) — reorderIssues updates the active saved view's sort, NOT the issue rows. If no active saved view, no-op.

  - `addSubIssue({ workspaceId, parentId, childId }: { workspaceId: string; parentId: string; childId: string }): Promise<Issue>`:
    - `tx.update(s.issues).set({ parentId: BigInt(parentId) }).where(eq(s.issues.externalId, childId)).returning()`
  - `linkIssues({ workspaceId, fromId, toId, linkType }: { workspaceId: string; fromId: string; toId: string; linkType: 'blocks' | 'relates_to' | 'duplicates' }): Promise<true>`:
    - Insert into an `issue_links` table if it exists; otherwise no-op with a console.warn for now (issue_links may be Phase 5). Read `apps/web/lib/db/schema/index.ts` to confirm.
