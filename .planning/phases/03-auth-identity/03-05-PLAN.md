<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HIBP API → breach-check.ts | Password prefix (5-char SHA-1) sent to external API; k-anonymity ensures full hash never leaves server |
| Upstash Redis → rate-limit.ts | Rate limit counters stored in Redis; HTTPS connection, auth token |
| Resend webhook → bounce-handler | Webhook signature verified before processing; untrusted input |
| WebAuthn → passkey.ts | Browser handles private key; server only receives public key credential |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-27 | Information Disclosure | HIBP check | mitigate | k-anonymity: only first 5 chars of SHA-1 hash sent to HIBP API; full hash never revealed |
| T-03-28 | Denial of Service | Rate limiter | mitigate | Per-endpoint limits prevent brute force; Upstash Redis ensures multi-instance consistency |
| T-03-29 | Tampering | Audit log | mitigate | Append-only table; no UPDATE/DELETE permissions on audit_log; written in same transaction as auth event |
| T-03-30 | Information Disclosure | Data export | mitigate | Export only contains requesting user's data; requires re-authentication; signed URL expires 7 days |
| T-03-31 | Elevation of Privilege | Account restoration | mitigate | Only within 30-day window; requires same email + password or passkey; audit event logged |
| T-03-32 | Spoofing | WebAuthn passkey | mitigate | Challenge-response protocol; origin bound; private key never leaves authenticator; server verifies signature |
| T-03-33 | Information Disclosure | Observability events | mitigate | Events contain hashed IDs only (userId hash, ipHash, uaHash); no PII in PostHog/Sentry |
| T-03-34 | Tampering | Email webhook | mitigate | Resend webhook signature verified with RESEND_WEBHOOK_SECRET before processing |
</threat_model>
