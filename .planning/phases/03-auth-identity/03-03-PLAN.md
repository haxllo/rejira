<objective>
Wire Better Auth's organization plugin mapped to our existing `workspaces`/`memberships`/`invitations`/`teams` tables from Phase 2. Build workspace creation, member invitations with signed tokens, role management (owner/admin/member/guest), and the workspace switcher. This is the multi-tenant backbone — every business query in Phase 4 will be scoped by the active workspace.

Purpose: Real multi-workspace support. Users create workspaces, invite teammates, manage roles, and switch contexts. The Phase 2 RLS policies read `auth.jwt() ->> 'sub'` and `current_workspace_ids()` — this plan ensures the JWT carries the right claims and the org plugin writes to our tables.
Output: Workspace CRUD helpers, invite system with signed tokens, 6 team components, 2 new pages, 24 Vitest tests, workspace switcher replacing the Phase 1 `?w=` hack.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Invite email → `/invite/[token]` | Signed token in URL; if intercepted before acceptance, attacker joins workspace |
| Client → `setActiveOrganization` | Workspace switching changes session JWT claims; server must re-validate on every request |
| Admin role → member management | Role changes are server-side authorized; client UI hides options but server enforces |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-16 | Spoofing | Invite token | mitigate | 256-bit signed token, single-use, 7-day expiry, hashed at rest; HTTPS-only |
| T-03-17 | Elevation of Privilege | Role management | mitigate | Server-side enforcement: cannot demote last owner, cannot self-demote, non-owners cannot promote to owner |
| T-03-18 | Elevation of Privilege | Workspace switcher | mitigate | `setActiveOrganization` validated server-side; RLS policies read session JWT — switching workspace updates claims |
| T-03-19 | Information Disclosure | Workspace list | mitigate | Only returns workspaces user is a member of; archived workspaces excluded; RLS on Phase 2 tables |
| T-03-20 | Tampering | Membership removal | mitigate | Owner cannot remove self; must transfer ownership first; audit_log written on role change |
| T-03-21 | Denial of Service | Bulk invite | accept | No rate limit on bulk CSV upload (100 emails max); scaling concern deferred to Plan 03-05 hardening |
</threat_model>
