<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Settings forms → Better Auth API | Profile/email/password changes validated server-side; CSRF protected via Better Auth |
| Onboarding wizard → workspace/invite APIs | Workspace creation and invitations go through server-side auth |
| Account deletion → 30-day soft delete | Data export button triggers GDPR-compliant export; delete initiates soft-delete |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-22 | Tampering | Password form | mitigate | Requires current password; new password validated against policy (12+ chars, HIBP check) |
| T-03-23 | Spoofing | Email change | mitigate | Dual-confirmation: tokens sent to both old and new email; both must be verified |
| T-03-24 | Elevation of Privilege | Onboarding workspace creation | mitigate | `allowUserToCreateOrganization: true` limited to 10 organizations; server enforces |
| T-03-25 | Information Disclosure | Data export | mitigate | Export contains only user's own data; requires re-authentication for sensitive operation |
| T-03-26 | Denial of Service | Account deletion | accept | Deletion is soft (30-day grace); user can restore by signing in; no DoS vector |
</threat_model>
