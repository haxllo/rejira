`supabase/migrations/0021_workspace_security_policy.sql`:
```sql
CREATE TABLE IF NOT EXISTS workspace_security_policy (
  workspace_id BIGINT PRIMARY KEY REFERENCES workspaces(id) ON DELETE CASCADE,
  require_2fa_for_admins BOOLEAN NOT NULL DEFAULT FALSE,
  require_2fa_for_members BOOLEAN NOT NULL DEFAULT FALSE,
  allowed_email_domains TEXT[] DEFAULT '{}',
  session_max_age_days INTEGER DEFAULT 7,
  disable_password_signin BOOLEAN NOT NULL DEFAULT FALSE,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- RLS: only workspace admins can read/write
ALTER TABLE workspace_security_policy ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Admins can manage workspace security policy"
  ON workspace_security_policy FOR ALL
  USING (is_workspace_admin(workspace_id, auth.jwt() ->> 'sub'));
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CSP → browser | Content-Security-Policy header restricts script sources; XSS mitigation at browser level |
| Workspace policy → sign-in flow | Policy enforced server-side in Better Auth hooks; client never sees raw policy rules |
| Locale detection → Accept-Language | Untrusted header parsed safely; only matches against allowlisted SUPPORTED_LOCALES |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-39 | Spoofing | Accept-Language header | mitigate | Locale string validated against allowlist; unknown locales fall back to "en" |
| T-03-40 | Tampering | Workspace security policy | mitigate | Only admins can modify; RLS enforced; audit log written on change; policies enforced server-side |
| T-03-41 | Information Disclosure | i18n dictionaries | accept | Translation files are public; no secrets or PII stored in locale strings |
| T-03-42 | Elevation of Privilege | require_2fa_for_admins bypass | mitigate | Policy enforced in Better Auth `signIn` hook server-side; cannot be bypassed by manipulating client state |
| T-03-43 | Denial of Service | npm audit | accept | Dependabot auto-PRs for patches; major updates require manual review |
</threat_model>
