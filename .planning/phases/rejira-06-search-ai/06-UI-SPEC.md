## Visual Hierarchy & Interaction Patterns

**⌘K (enhanced):**
- Search results grouped: Navigation → Issues → Projects → AI Answers
- Each group has a sticky section heading with count badge
- AI Answers section at the bottom with a sparkle/accent icon prefix
- Result items: icon + title + project key (mono) + match highlights in accent
- Keyboard: `↑` `↓` to navigate, `Enter` to select, `Esc` to dismiss, `Tab` to cycle groups
- Hover state: `--color-surface-1` background on result items
- Selected state: `--color-accent-soft` background + focus ring

**AI Triage (create-issue dialog):**
- "AI Assist" button below title input, right-aligned
- Loading state: spinner with "Generating suggestions…"
- Result: inline suggestion cards (title, description, priority, assignee) with "Apply" and "Dismiss" per suggestion
- Error state: inline error message with "Retry" link

**Summarize (issue drawer):**
- "Summarize this issue" in the overflow menu (`MoreHorizontalIcon`)
- Result shown as a collapsible banner below the issue title
- Loading: skeleton placeholder (3 lines, shimmer animation)
- Error: inline error with "Try again" link

**Facet filters (⌘K expanded view):**
- Horizontal filter pill row below search input
- Pills: Project, Status, Assignee, Label, Cycle
- Active pill: `--color-accent` text + subtle border
- Inactive pill: `--color-text-muted` text + `--color-surface-1` background
- Count badge on each active facet value
